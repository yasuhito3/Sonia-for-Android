# 🎵 Sonia for Android

スマホのアイコンをタップするだけで始まる、Android 用のハイレゾ志向ミュージックプレイヤーです。  
ffmpeg → mpv の音声パイプで 10 バンド EQ・ゲイン調整が効き、ローカル音楽・ネットラジオ・YouTube / SoundCloud を同じ音質設定で楽しめます。

> 🇬🇧 English: see [Quick start](./Quick%20start)

---

## ✨ できること

- `/sdcard/Music` の音楽再生（FLAC / WAV / MP3 / M4A / OGG ほか）
- 10 バンド EQ プリセット・低音／高音スライダー（±12dB）・ゲインプリセット
- **YouTube / SoundCloud** のストリーム再生（EQ もそのまま効く）＋プレイリスト
- インターネットラジオ 10 局、ジャケット画像表示
- **ホーム画面のアイコンから、アプリのように起動**
- 画面を消しても再生が止まらない（再生中だけ自動で省電力ロックを保持）
- 同じ Wi-Fi の別端末からも操作可能

## 🚀 はじめかた（3 ステップ）

### ① Termux を入れる（初回のみ）

[F-Droid](https://f-droid.org/packages/com.termux/) から次の **2 つ** を入れます。

| アプリ | 役目 |
|---|---|
| **Termux** | Sonia が動く土台（必須） |
| **Termux:Widget** | ホーム画面のショートカット用（おすすめ） |

> ⚠️ Termux 系アプリは **すべて F-Droid 版で統一** してください（Google Play 版とは混ぜられません）。

### ② インストール（コピペして Enter）

Termux を開いて、次の 1 行を貼り付けます。

```bash
curl -sL https://raw.githubusercontent.com/yasuhito3/Sonia-for-Android/main/install.sh | bash
```

必要なものは全部自動で入ります。途中で「ストレージへのアクセス」を聞かれたら **許可** を押してください。  
終わると自動で Sonia が開きます 🎉

### ③ ホーム画面にアイコンを置く

Sonia が開いたブラウザ（Chrome）で:

**右上のメニュー（⋮）→「アプリをインストール」**（または「ホーム画面に追加」）

> Sonia の **⚙ SET タブ → 「📲 ホーム画面に追加」** ボタンからも行えます。

これで、ホーム画面に Sonia アイコンができます。ブラウザの枠のない、アプリそのままの見た目で開きます。

## 📱 ふだんの使いかた

Sonia は **Termux の画面の中で動きます**。ブラウザは、その操作画面です。

1. **ホーム画面の「Sonia」ショートカット（Termux:Widget）をタップ**、または Termux で `musica` と入力  
   → 数秒でブラウザが自動で開きます
2. 曲を選ぶ（MUSIC / RADIO / STREAM）
3. **ホームボタンで画面を離れても、再生は続きます**（Termux は閉じずに、そのままにしておいてください）
4. 終わったら、SET タブの **「⏻ Sonia を終了」**

> ⚠️ 「最近使ったアプリ」から Termux を **スワイプで消さない** でください。消すと Sonia も止まります。

### 「Sonia はお休み中です」と出たら

アイコンから開いたときに Sonia が止まっていると、この画面になります。  
**Termux:Widget の「Sonia」ショートカットをタップ** して、起こしてあげてください。つながると、この画面は自動で切り替わります。

> 💡 ホーム画面を長押し → ウィジェット → Termux:Widget → ショートカットから「Sonia」を選ぶと、置けます。

## 🗂 画面構成

| タブ | 内容 |
|------|------|
| **NOW** | 再生中の曲・コントロール・EQ・ゲイン |
| **MUSIC** | ローカル音楽（リスト／ジャケット表示） |
| **RADIO** | ネットラジオ局 |
| **STREAM** | YouTube / SoundCloud の検索・再生・プレイリスト |
| **SET** | プリセット・フォルダ設定・アプリ化・終了ボタン |

### STREAM の使いかた

1. `▶ YouTube` か `☁ SoundCloud` を選ぶ
2. 曲名・アーティスト名を入れて「検索」
3. 曲をタップ → すぐ再生（EQ・ゲイン設定がそのまま適用）
4. **＋ボタン** でプレイリストに追加（✓ に変わる）→ 下のバーの **▶ 再生** で連続再生

> 音が出るまで数秒かかります（yt-dlp が URL を探している時間です）。

## 🔧 `musica` コマンド（Termux）

| コマンド | 内容 |
|---|---|
| `musica` | 起動してブラウザで開く |
| `musica stop` | 終了する（別の画面から） |
| `musica status` | 動作状況・接続先を表示 |
| `musica update` | 最新版に更新 |
| `musica autostart on` / `off` | スマホ起動時の自動起動（実験的・機種により動かない場合あり） |
| `musica start` | 裏で起動（実験的・Android に止められる機種あり） |
| `musica log` | ログを見る |

アプリ内の **SET → 「⏻ Sonia を終了」** でも終了できます。

## ❓ こまったとき

**曲が出てこない**  
→ Termux で `termux-setup-storage` を実行して許可 → SET タブの「再スキャン」。曲は `/sdcard/Music/` に入れてください。

**YouTube が再生できない（`403 Forbidden` など）**  
→ YouTube 側の仕様変更で、yt-dlp が古いと起きることがあります。Termux で更新してください（数秒で終わります）。

```bash
pip install -U yt-dlp
```

`musica update` でも、Sonia と一緒に更新されます。Sonia は、拒否されたら自動で別の方法に切り替えます（切り替わった内容は `musica log` で見られます）。

**音が途切れる（音飛び）**  
→ SET タブの **「🛡 音飛び対策（先読みバッファ）」** を「大」→「最大」の順に上げてみてください（次の曲から効きます。大きいほど、一時停止や曲送りの反応が少し遅くなります）。  
それでも続くときは、次も確認してください。
- Termux の電池設定が **「制限なし」** になっているか
- **Bluetooth のイヤホン／スピーカー** を使っている場合は、有線や本体スピーカーでも起きるか（Bluetooth 側が原因のことも多いです）
- 画面を点けている間だけ直るなら、省電力機能が原因です（省電力モードを切る）

**Termux の画面が反応しなくなった**  
→ `musica` の実行中は、その画面が Sonia の画面になるのが正常です。左端から右へスワイプして「NEW SESSION」で新しい画面を開くと、`musica stop` などを打てます。

**画面を消すと音が止まる**  
→ Android の設定 → アプリ → Termux → バッテリー → **「制限なし」** にしてください。機種によっては、これが一番効きます。

**アイコンから開くと「お休み中」になる**  
→ Termux:Widget の「Sonia」ショートカットで起こしてください。Termux を最近のアプリから消すと、Sonia も止まります。

**「アプリをインストール」が出ない**  
→ Chrome で `http://localhost:8080` を開いているか確認してください（別端末や IP アドレス経由ではインストールできません）。メニューに「ホーム画面に追加」があれば、それでも OK です。

## 🎛 再生エンジン

```
ffmpeg（EQ／ゲイン処理）→ mpv（音声出力）
```

ストリーム再生も同じ経路を通るので、EQ・ゲイン・低音高音スライダーがすべて有効です。

対応フォーマット: `.wav` `.flac` `.wma` `.aiff` `.aif` `.mp3` `.m4a` `.aac` `.ogg` `.opus`

## Xubuntu24 版との違い

| 項目 | Android 版 | Xubuntu24 版 |
|------|-----------|-------------|
| 音声出力 | mpv（自動 BT/有線切替） | aplay / ALSA |
| UI | モバイル Web ブラウザ（アプリ化可） | curses TUI |
| ジャケット | ブラウザ内表示 | feh |
| 音声認識 | 非対応（将来予定） | vosk |

Xubuntu24 版へのステップアップで、さらに高音質・多機能になります。  
→ https://sites.google.com/view/aimusicplayer-sonia/
